# OpenStatus repository instructions

## JXHQ Lab publishing contract

This public repository is eligible for automatic display on `https://jxhq.net/lab/`.

Whenever the repository is renamed, published, archived, or substantially updated:

- keep the GitHub description and homepage accurate;
- keep its topics representative of the project;
- use `hide-from-lab` only when it should disappear from JXHQ Lab;
- optionally use `featured`, `prototype`, or `probably-broken` to influence its Lab presentation;
- ensure the README, license, live deployment, and Lab card remain consistent;
- never commit or expose CapRover tokens, credentials, private hostnames, or other secrets.

Check the Lab presentation before considering repository-facing work complete.
